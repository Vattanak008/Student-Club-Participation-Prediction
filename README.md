# Project Background

Paragon International University is one of the leading Univerity in Cambodia, Southeast Asia, which was found in 2010, providing youth with many levels of academics including Bachelor, Master, and PhD.

One of the University mission's is to support students' life outside of academic life which result in a new branch of office, the Student Clubs and Cultural Activities Center, which was introduced back in 2015. Since the Covid-19 pandemic, student clubs has suffered from decreased in participation in their events and activity, although the number is recovering. That is why this project is aimed to predict whether if there is sufficient amount of participation for the next academic year of student club.

Insights and recommendation is provided on the the following key areas:
* Participation Predictive Analysis
* Recommendation and Conclusion
